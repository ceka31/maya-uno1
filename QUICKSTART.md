# 🚀 Quick Start Guide - 3D UNO Game

## 1️⃣ Setup (30 seconds)

```bash
# Install dependencies
npm install

# Start the game server
npm start
```

## 2️⃣ Open the Game

Open your browser and go to:
```
http://localhost:3000
```

## 3️⃣ Play (2+ players required)

### First Player
1. Enter your name
2. Enter a room ID (e.g., "room1")
3. Click "Join"

### Second Player (in another browser window/tab)
1. Enter your name
2. Enter the **same room ID** (e.g., "room1")
3. Click "Join"

### Start Game
- Click "Start Game" button
- Each player gets 7 cards
- Follow the turn order displayed

## 🎮 Basic Controls

| Action | How |
|--------|-----|
| Play Card | Click any card in your hand |
| Draw Card | Click "ÇEK" (DRAW) button |
| Call UNO | Click "UNO!" button when you have 1 card left |
| Chat | Type messages in chat area |

## 🎨 Visual Features

✨ **3D Table** - Rotating 3D model that loads as the game starts  
🎴 **3D Cards** - Beautiful animated cards on the table  
💫 **Particle Effects** - Explosions when playing cards  
🔊 **Sound Effects** - Audio feedback for all actions  
⚡ **Glowing Effects** - Interactive visual feedback  

## 🔊 Sound Effects

- **Card Play** - Double beep sound
- **UNO Call** - Rising tone sequence
- **Draw Card** - Single low tone
- **Win** - Victory fanfare

## 📊 Game Rules Quick Reference

| Card | Effect |
|------|--------|
| 0-9 | Match color or number |
| Skip | 🚫 Skip next player |
| Reverse | 🔄 Reverse direction |
| Draw 2 | 📥 Next player draws 2 |
| Wild | 🔮 Change color |
| Draw 4 | 🔮 Wild + next draws 4 |

## ⚠️ Common Issues

**Problem:** Can't see cards on table
- Wait 2-3 seconds for 3D model to load

**Problem:** Sound not working
- Check browser volume and speaker settings
- Ensure audio is not muted

**Problem:** Can't join friend's game
- Make sure you use the **exact same room ID**
- Refresh page if connection issues occur

## 💡 Pro Tips

1. 🔊 Keep volume at 50% to enjoy effects without distraction
2. 👀 Watch the active player highlight to know whose turn it is
3. ✋ Plan ahead - see other players' card counts
4. 📞 Use chat to coordinate with players
5. 🎯 Remember to call UNO when you have 1 card!
