## 🎮 Playing the Game

### Basic Controls

```
Click Card          → Play the card
Click ÇEK           → Draw a card
Click UNO!          → Call UNO (when on 1 card)
Type Chat           → Send message
Choose Color Modal  → Pick color for Wild
```

### Game Rules (Quick Reference)

- **Match** - Color or number with previous card
- **Skip** - Skip next player
- **Reverse** - Reverse play direction  
- **Draw2** - Next player draws 2
- **Wild** - Choose any color
- **Draw4** - Wild + next draws 4

For full rules, see [README.md](./README.md)
